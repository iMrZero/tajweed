# Tajweed

موقع/تطبيق عربي يساعد على دراسة أحكام التجويد بطريقة منظمة وسهلة. يناقش القواعد الأساسية للمصحف والتلاوة مع تنظيم حسب الفئات وقواعد التفصيل.

## المميزات

- تصفح القواعد حسب الفئات
- عرض تفصيلي لكل قاعدة مع شرحها
- واجهة مناسبة للقراءة في الليل والنهار
- دعم التوجيه وربط الصفحات باستخدام TanStack Router
- بناء باستخدام React و TypeScript و Vite

## التقنيات المستخدمة

- React 19
- TypeScript
- Vite
- TanStack Router
- React Icons / Lucide React

## المتطلبات

- Node.js 18 أو أحدث
- pnpm

## التثبيت

```bash
pnpm install
```

## التشغيل المحلي

```bash
pnpm dev
```

بعد ذلك سيتم تشغيل المشروع محليًا عادةً على:

```text
http://localhost:5173
```

## الأوامر المتاحة

```bash
pnpm dev      # تشغيل المشروع في وضع التطوير
pnpm build    # بناء المشروع للإنتاج
pnpm lint     # فحص التعليمات البرمجية
pnpm preview  # معاينة نسخة البناء المحلية
```

## هيكل المشروع

```text
src/
  components/      # المكونات المشتركة والواجهات
  routes/          # صفحات التطبيق والتوجيه
  data/            # بيانات القواعد والتصنيفات
  context/         # سياقات التطبيق
  styles/          # ملفات التنسيق
  util/            # أدوات مساعدة
public/            # الملفات العامة
```
